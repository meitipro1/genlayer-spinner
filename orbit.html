Where it goes

A full page load on an ecosystem surface

Pending

Ecosystem pages, landing pages, a marketing route load. 240px and up, never in a button. Nineteen chips is nineteen image requests, so every one of them is lazy loaded and decoded off the main thread. Nothing else in the set loads a single file.

The loop

7s to 18s per ring, closing on its own first frame

Easing is linear, five rates. Nothing here uses JavaScript, so a stalled main thread does not stall the spinner.

The reasoning

Why this one is GenLayer

The idea

Orbit

The rest of the set draws the protocol. This one draws who is on it. A full page load on an ecosystem or landing surface is the one moment a visitor will hold still long enough to read nineteen logos, so the wait becomes the pitch instead of an apology for it. Rings turn at 7, 9.5, 12, 15 and 18 seconds, which are deliberately not multiples of each other, so the arrangement never repeats itself inside a load anyone will sit through.

Changed from the design files

What the port fixed

The chips were sheared. Each one unwound the ecliptic tilt first and its own arm angle second, and rotations do not commute, so what was left on the image was Rx(64) Rz(deg) Rx(-64) Rz(-deg) - the identity only at 0 and 180 degrees. Every logo in between rendered as a tilted sliver. Unwinding in reverse, rotate(-deg) then rotateX(-64deg), cancels the chain exactly, and the accumulated matrix on every chip now measures as a pure translation. Two more: an `img { max-width: 100% }` in the host page, which is in Tailwind's preflight and in most other resets, clamped every chip to zero wide against the zero width point it hangs from, so the component now sets max-width itself. And the ring borders were carrying the rotation that walks the chips round, turning a square box that paints a circle to no effect; the border is static and a carrier inside it does the turn. Ring diameters came down to 0.78 of the footprint, because a ring tilted 64 degrees under a point projection paints wider than it measures, and perspective moved from 1600px to 4.2em so the tilt holds at any size.

/* ---------- orbit ----------
   GenLayer at the centre, the ecosystem in orbit on five rings.

   Not a general-purpose spinner: it needs 240px or more and it loads one image
   per project, so it belongs on an ecosystem or landing surface and never in a
   button. Ring diameters and chip sizes are fractions of the footprint, so the
   whole system still scales on one number. */

.gl--orbit {
  perspective: 4.2em;
  transform-style: preserve-3d;
}
.gl-orbit {
  position: relative;
  display: grid;
  place-items: center;
  width: 1em;
  height: 1em;
  perspective: 4.2em;
  transform-style: preserve-3d;
}
.gl-orbit-sweep {
  position: absolute;
  inset: 0.02em;
  border: 1px dashed color-mix(in oklab, currentColor 22%, transparent);
  border-radius: 50%;
  animation: gl-sweep 22s linear infinite;
}
/* The ring's border does not spin - only the carrier inside it does. A square
   box painting a circle has a bounding box that grows by root two as it turns,
   which is a footprint nothing is actually painting into. */
.gl-orbit-ring {
  position: absolute;
  border-radius: 50%;
  border: 1px solid color-mix(in oklab, currentColor 18%, transparent);
  transform: rotateX(64deg);
  transform-style: preserve-3d;
}
.gl-orbit-spin {
  position: absolute;
  inset: 0;
  transform-style: preserve-3d;
  animation: gl-ring linear infinite;
}
/* A static arm carries the project's angle on the ring, the hold counter-spins
   the ring's rotation, and the chip unwinds its own arm angle and then the
   ecliptic tilt.

   That order is the whole trick. Rotations do not commute, so the chip has to
   undo the chain in reverse: rotate(-deg) then rotateX(-64deg). Tilting first
   leaves Rx(64) Rz(deg) Rx(-64) Rz(-deg) on the image, which is the identity
   only at 0 and 180 degrees and shears every chip in between into a sliver. */
.gl-orbit-arm {
  position: absolute;
  inset: 0;
  transform-style: preserve-3d;
}
.gl-orbit-hold {
  position: absolute;
  top: 50%;
  left: 100%;
  width: 0;
  height: 0;
  transform-style: preserve-3d;
  animation: gl-anti linear infinite;
}
.gl-orbit-hold img {
  position: absolute;
  display: block;
  /* The hold is a zero by zero point on the ring, so a host reset of
     `img { max-width: 100% }` - which is in Tailwind's preflight and in most
     other resets - clamps every chip to 0 wide while leaving its height alone.
     The component defends itself rather than asking the project not to. */
  max-width: none;
  max-height: none;
  transform: rotateX(-64deg);
}
.gl-orbit-sun {
  position: relative;
  width: 0.195em;
  height: 0.195em;
  fill: currentColor;
  animation: gl-sun 2.6s ease-in-out infinite;
}
