The reasoning

Why this one is GenLayer

The idea

Vault

Finality as a single object. A sealed block turning over is what a finalized transaction looks like if you had to draw one, and putting the mark on four faces means the brand never rotates out of view. The teal marks it as the one variant that is not the default.

Changed from the design files

What the port fixed

Three things. The same slab bug as the prism, in a sharper form: .5em faces on a .5em block made the box twice as deep as it was wide, so the side faces never met the front, and faces now sit at a quarter of the footprint. The floor bar was a child of the block, which meant it inherited preserve-3d and pitched and rolled along with the thing it is supposed to be lying under, and it is now a sibling. The vanishing point moved to 50% 39%, because the padding under the block is larger than the padding above it and a centred origin was tilting the block upward.

/* ---------- vault ----------
   A solid block tumbling with the mark on four faces.

   Faces sit at a quarter of the footprint, half the block's own side, so the
   six of them close into a cube rather than a slab. The floor bar hangs below
   the block, so the padding is asymmetric: .5em of block, .14em of headroom
   and .36em underneath for the bar and its stretch. */

.gl--vault {
  position: relative;
  perspective: 13.5em;
  /* the padding is asymmetric, so the vanishing point has to be moved off the
     padding box's centre and onto the block's */
  perspective-origin: 50% 39%;
  color: var(--gl-teal, #008081);
  padding: 0.14em 0.25em 0.36em;
  box-sizing: content-box;
}
.gl-box {

  height: 0.5em;

}
